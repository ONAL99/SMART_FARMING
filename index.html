Sistem Irigasi Otonom

Sistem pemantauan dan irigasi otomatis untuk tanaman cabai berbasis dua ESP32 yang berkomunikasi secara peer-to-peer menggunakan protokol ESP-NOW. Bekerja penuh di edge — tanpa internet, tanpa cloud, tanpa biaya langganan.

02 — Keunggulan

Mengapa Sistem Ini?

01

Biaya Sangat Murah

Seluruh komponen — ESP32, DHT22, sensor kapasitif, relay, dan pompa DC — mudah didapat dengan harga terjangkau. Tidak ada biaya cloud, server, atau langganan bulanan. Total biaya hardware jauh di bawah solusi komersial serupa.

02

Sepenuhnya Otonom

Controller memproses data sensor setiap 500 ms dan mengambil keputusan irigasi secara mandiri berdasarkan threshold agronomis cabai. Pompa menyala dan mati otomatis — tidak butuh operator 24 jam.

03

Local Edge — Tanpa Internet

ESP-NOW berkomunikasi langsung antar perangkat tanpa melalui router, modem, atau koneksi internet. Ideal untuk lahan pertanian terpencil. Latensi rendah, tidak bergantung infrastruktur eksternal.

04

Respons Cepat

Interval kirim data 500 ms tanpa blocking delay. Switch dibaca setiap cycle loop untuk respons instan. Perintah pompa dikirim hanya saat ada perubahan state — menghemat bandwidth ESP-NOW dan mempercepat eksekusi.

05

Keamanan Berlapis

Safety timer otomatis mematikan pompa jika menyala lebih dari 5 menit 10 detik, mencegah kerusakan pompa atau banjir lahan akibat sensor error atau gangguan komunikasi ESP-NOW.

06

Kontrol Manual Terintegrasi

Dua switch latching memungkinkan operator beralih ke mode manual kapan saja tanpa mematikan sistem. Mode AUTO dan MANUAL dapat berganti seamless — sistem kembali otomatis begitu switch dikembalikan.

03 — Threshold

Parameter Kontrol Cabai

Threshold disusun berdasarkan literatur agronomi tanaman cabai (Capsicum annuum). Sistem menggunakan logika prioritas bertingkat — kondisi dengan risiko tertinggi selalu dievaluasi lebih dahulu. Mekanisme hysteresis (ON <55% / OFF ≥75%) mencegah pompa nyala-mati terlalu cepat.

Kondisi Parameter Nilai Aksi Alasan Agronomis
Kelembaban udara ekstrem RH udara > 90% PAKSA OFF Tanah jenuh, risiko tinggi busuk akar dan serangan jamur Phytophthora
Tanah terlalu kering Soil moisture < 55% ON Cabai sangat sensitif kekeringan, terutama fase pembungaan dan pembuahan
Suhu tinggi + tanah belum cukup Suhu & Soil >32°C & <75% ON Evapotranspirasi meningkat, tanaman kehilangan air lebih cepat dari biasa
Tanah sudah cukup basah Soil moisture ≥ 75% OFF Kelembaban optimal tercapai, hentikan irigasi (hysteresis 55–75%)
Kondisi optimal keseluruhan Semua parameter 24–30°C · 60–80% · 55–75% OPTIMAL Seluruh parameter dalam rentang ideal pertumbuhan cabai
Safety timer terlampaui Durasi pompa ON > 5 menit 10 dtk AUTO OFF Proteksi hardware, mode kembali ke AUTO, cegah banjir lahan
Urutan Prioritas (tertinggi → terendah):
RH > 90% (paksa OFF) → Soil < 55% (ON) → Suhu > 32°C + Soil < 75% (ON) → Soil ≥ 75% (OFF) → Safety Timer (auto OFF)
04 — Cara Kerja

Alur Sistem

⚡
Boot & Handshake
Kedua ESP32 menyala, inisialisasi WiFi STA mode, daftarkan peer ESP-NOW menggunakan MAC Address masing-masing.
📡
Baca Sensor
DHT22 dibaca tiap 2000 ms non-blocking. Soil moisture dibaca tiap 500 ms tanpa delay. Data dikemas dalam struct SensorData.
→
Kirim via ESP-NOW
Node sensor mengirim paket SensorData ke controller tiap 500 ms. Latensi ESP-NOW <2 ms, tidak membutuhkan router.
🧠
Proses Threshold
Controller mengevaluasi data berdasarkan 4 aturan threshold prioritas. Keputusan pompa hanya dikirim saat state berubah.
←
Kirim Perintah
CommandData (pompaNyala, modeManual) dikirim balik ke sensor node via ESP-NOW. Eksekusi relay langsung tanpa delay tambahan.
💧
Eksekusi Aktuator
Relay diaktifkan (active LOW) sesuai perintah. Counter penyiraman dan durasi diakumulasi di controller, ditampilkan di LCD.

05 — Potensi Pengembangan

Roadmap & Ide Lanjutan

Hardware Minor
RTC + Jadwal Penyiraman
Tambah modul RTC DS3231 untuk menjadwalkan penyiraman pada jam tertentu, memungkinkan irigasi pagi/sore otomatis terlepas dari kondisi sensor.
Effort: Medium
Software Minor
Logging ke SD Card
Simpan data sensor dan riwayat penyiraman ke SD card dalam format CSV. Memungkinkan analisis historis dan audit kondisi tanaman.
Effort: Medium
Hardware Minor
Panel Surya + Baterai
Node sensor ditenagai panel surya 5W + baterai Li-Ion. Aktifkan light sleep ESP32 di antara interval baca sensor untuk efisiensi daya maksimal.
Effort: High
Software Major
Dashboard Web via WiFi AP
Controller ESP32 berjalan sebagai access point + web server. Dashboard real-time dapat diakses dari HP tanpa internet — tetap local edge.
Effort: High
Sensor
Multi-Titik Soil Moisture
Tambah 2–3 sensor soil di titik berbeda pada lahan. Controller menghitung rata-rata atau threshold per zona untuk irigasi yang lebih presisi.
Effort: Medium
AI / ML
Adaptive Threshold via ML
Kumpulkan data historis (logging), latih model ringan untuk menyesuaikan threshold secara adaptif berdasarkan fase pertumbuhan tanaman cabai.
Effort: Very High
